# Roadmind — Hugging Face Space

This file is the README for the **Hugging Face Space** only (the Space needs the
settings block above). The project README is in the GitHub repository.

To deploy: copy the whole repository into the Space, then replace the Space's
README.md with this file. Add `GEMINI_API_KEY` under Space → Settings →
Variables and secrets (optional). Add `ROADMIND_DETECT_EVERY=2` there too —
free CPU hardware is slower than a laptop.
